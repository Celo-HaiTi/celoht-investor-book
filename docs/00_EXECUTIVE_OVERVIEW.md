## One-paragraph summary

CeloHT is an open-source, community-governed initiative building financial
inclusion, blockchain education, and reforestation programs for Haiti, using
the Celo network as payment infrastructure. It is organized around three
public pillars — Education, Agent Network, Reforestation — and is developed
in the open under the `Celo-HaiTi` GitHub organization.
