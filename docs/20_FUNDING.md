# 20 — Funding

CeloHT funding, where sought, is described as **project financing /
organizational funding** — not a token investment, not a securities offer,
and not a guarantee of return. See [`../NO_TOKEN_POLICY.md`](../NO_TOKEN_POLICY.md).

## Stated use-of-funds categories

- Infrastructure (RPC, hosting, database)
- Security (audits, when commissioned)
- Product development (dApp, backend, indexer)
- Education program development and delivery
- Agent network expansion
- Reforestation program funding
- Open-source development and maintenance capacity

## Funding target

**CURRENT FUNDING TARGET REQUIRES VERIFICATION.** No prior fundraising
figure is carried forward into this edition. If a current, dated funding
target exists, it should be added here with its source and date rather
than assumed from historical material.

## What this section is not

This is not an investment offer, a securities disclosure, or a
solicitation. Anyone evaluating a funding relationship with CeloHT should
conduct independent legal and financial due diligence; see
`docs/25_DUE_DILIGENCE.md` and `docs/27_LEGAL_AND_DISCLOSURES.md`.
