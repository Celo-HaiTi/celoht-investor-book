# No-Token Policy

**Status:** PROJECT-REPORTED (consistent across all inspected Celo-HaiTi repositories)

CeloHT does not have, has never had, and does not plan to launch a native
CeloHT token.

Specifically, CeloHT does **not**:

- issue a CeloHT token of any kind
- run an ICO, IDO, presale, or token sale
- offer token-weighted governance
- promise or imply investment returns of any kind
- treat CELO or USDm as a CeloHT-issued asset

## Role of CELO and USDm

- **CELO** is the native gas/governance asset of the Celo network. CeloHT
  uses it strictly for transaction fees. CeloHT does not control, issue, or
  govern CELO.
- **USDm** is the canonical stable-value currency used for payments within
  the CeloHT ecosystem (agent network, education fees where applicable,
  reforestation contributions). USDm is not issued or controlled by CeloHT.

## Governance without a token

CeloHT's governance model (see [`docs/13_GOVERNANCE.md`](./docs/13_GOVERNANCE.md))
uses a one-member-one-vote structure, not token-weighted voting. Voting
weight is never a function of USDm or CELO holdings.

## If you are asked to invest in a "CeloHT token"

Any offer to sell, pre-sell, or allocate a "CeloHT token" is not
affiliated with this project. This repository is the canonical reference
for CeloHT's identity and should be used to verify any such claim.
