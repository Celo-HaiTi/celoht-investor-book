# 22 — Metrics

This edition includes no fabricated metrics. Every metric published under
the CeloHT name should carry all of the following fields before being
cited externally:

| Field | Description |
|---|---|
| Metric | What is being measured |
| Value | The number |
| Date | When it was measured/reported |
| Geography | Where it applies |
| Definition | Precisely what counts (e.g., "educated" = completed which course?) |
| Source | Where the number comes from |
| Verification level | `verified` / `reported` / `estimated` / `planned` / `unavailable` |
| Last updated | Date this entry was last reviewed |

## Anti-fabrication policy

- A target must never be presented as an achieved result.
- A projection must never be presented as historical performance.
- A testnet transaction must never be presented as production adoption.
